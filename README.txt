顺办 · 单机版 v1.0
===================

这是一个纯单机网页应用：不联网（除可选 AI 功能外）、无账号、无服务器，
所有任务和课表数据只保存在打开它的那台设备的浏览器里（localStorage）。

【文件说明】
- index.html   主程序（单文件，已内嵌全部代码）
- sw.js        离线缓存（部署到 http(s) 地址后生效，可离线打开）
- manifest.webmanifest + icon-*.png  加到手机主屏幕时当 App 用

【怎么用】
方式一（最省事）：把整个文件夹丢到任意免费静态托管
  - GitHub Pages / Cloudflare Pages / Gitee Pages 均可，几秒钟就能上线，
    得到一个网址，发给朋友，各自打开各自用，互不相干、永久免费。
方式二：直接双击 index.html 用浏览器打开也能用
  （注意：file:// 方式下 AI 功能会因浏览器安全限制不可用，任务/课表功能正常）。

【数据与备份】
- 数据只存在本机浏览器：清缓存、换浏览器、换设备都会丢。
- 设置页里可以「导出备份 / 导入备份」，建议定期导出存一份。

【可选 AI 功能（自带钥匙版）】
- 图片识别课表、AI 语音录入、复盘搭档三个功能需要调用 Moonshot 模型。
- 在 设置页 填入自己在 platform.moonshot.cn 申请的 API Key，
  用的是你自己的额度，Key 只存在你自己设备上。
- 不填 Key 应用照常使用，只是没有这三个 AI 功能。
- Moonshot 开放平台没有免费额度，需要小额充值激活（最低约 1 美元），
  kimi-k2.6 模型价格很低，正常使用一个月通常几毛钱。

【录入规则】
- 快速记一件事：默认放进「今天」。
- 要放到别的日子：用「详细添加」选日期；
  或在课表页用 AI 录入（说「周五交实验报告」会自动放到周五）。
